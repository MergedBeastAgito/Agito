## Transcript

How should a capture of an answer become a document rather than a folder of
text?

Treat the note as a value. The renderer that writes it is a function from an
answer and its metadata to a string, so the same answer read twice produces the
same bytes and a diff between two notes is the facts that changed.

Computer mode is a different capability: it runs tools on the caller's behalf,
so a driver that silently used it would be spending somebody else's allowance.
The port refuses it rather than pretending it was never asked for.

The page's furniture is the part that has to go. A sidebar label, a clock, the
elapsed time, the row of follow-up prompts: each is a whole line, and none of
them is a word inside a sentence.
