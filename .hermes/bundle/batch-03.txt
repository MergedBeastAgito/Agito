# Goal

TimeLine's decision corpus is 76 numbered records with a frontmatter contract, a
generated index, and a board that publishes them as issues. Agentic has none of that,
and should not grow one by copying - the corpus is a product decision with its own
cost, and the shape has to fit a repository whose subject is a swarm rather than a
site.

This card is a plan, not an implementation. It exists so the house-style card can
leave room for it and so nobody invents a half-corpus in the meantime.

# What a record would be here

A decision record in Agentic would answer a different question from TimeLine's. There
the subject is a surface: which band sits under which, which field decides
publication. Here the subject is a mechanism: what owns authority, what an effect
carries, what a generation is, what a lease fences.

So the frontmatter cannot be copied verbatim. The fields that survive:

- `title`, `date`, `status` (`proposed` / `settled` / `superseded`), `owner`;
- `applies_to` - the crate or document the decision binds;
- `supersedes` / `superseded_by`;
- `depends` - the records or cards it needs.

The fields that do not survive as they are:

- `category: <Kind>/<Subject>` - TimeLine's two vocabularies are about surfaces and
  policy. Agentic needs its own closed set or none at all; a taxonomy invented to look
  consistent is worse than no taxonomy.
- `horizon` - TimeLine uses it to say what a decision presupposes. Here the useful
  axis is reversal cost, which the external review already ranks.

# What the card should decide, before writing any record

1. **Whether the corpus is worth it.** Three records that are read beat seventy-six
   that are generated. If the answer is "yes, but small", the corpus starts at five.
2. **Which existing documents become records.** `docs/Design.md`,
   `docs/Observability.md`, `docs/Reflection.md` and `docs/Scope.md` already contain
   decisions; a record that restates them is duplication unless it supersedes them.
3. **Whether a board exists at all.** TimeLine publishes records as issues because a
   person triages them. Agentic's work is already on a kanban board; a second board
   needs a reason.
4. **The gate.** If records exist, a check must fail when one is malformed - the same
   discipline as `Scripts/Feed.mjs`, not a separate toolchain.

# What it must not do

- Copy `rfc_board.py` or its project field model.
- Import TimeLine's `RFC-Classification.md` vocabularies.
- Number anything before the first record's content is agreed.

# Handoff, when this card is opened

A one-page proposal naming: the record count, the field set, which existing documents
are absorbed or superseded, whether a board exists, and the single command that gates
a malformed record. No records written until that proposal is accepted.

# Goal

`packages/runtime` is a manifest and an empty entry point. Give it the four things
its manifest promises - admission, leases, budgets, cleanup - so a capability can
be run without knowing how it is scheduled.

Done means: `node --test` passes with no browser, and a lease that expires while
its worker is still running refuses that worker's late write.

# What exists

| Path | What it gives you |
| --- | --- |
| `packages/runtime/module.json` | port `agentic.runtime`, errors `admission-refused`, `lease-held`, `budget-exhausted`, state `holds-workspace` |
| `docs/Reflection.md` | the invariant the runtime enforces: the manifest a runtime reports is the manifest it enforces |
| `.hermes/research/432b4991.md` | the state chart: execution, disclosure, scheduling and generation as concurrent coordinates, with a shared admission predicate at every authoritative effect |

# Required behaviour

Declare `src/Port.ts`:

```ts
export type StateClass = "stateless" | "holds-transport" | "holds-identity" | "holds-workspace";
export type Lease = { id: string; resource: string; fence: number; expiresAt: number };
export type Budget = { deadline: number; operations: number };

export interface Runtime {
	/** Admit a run, or refuse it with the reason. */
	admit(request: { capability: string; state: StateClass; generation: number }): Promise<{ ok: true } | { ok: false; reason: string }>;
	/** Claim a resource, or fail because one is held. */
	claim(resource: string, ttlMs: number): Promise<Lease>;
	/** Extend a lease, only for the holder of the current fence. */
	renew(lease: Lease, ttlMs: number): Promise<Lease>;
	/** Write under a lease; refuse when the fence is stale. */
	withLease<T>(lease: Lease, write: () => Promise<T>): Promise<T>;
	/** Release, always. Never throws. */
	release(lease: Lease): Promise<void>;
}
```

Rules:

1. **Admission is per effect, not per run.** `withLease` re-checks the fence; a
   lease that expired mid-run makes the next write fail rather than land late.
2. **A held resource is refused, not queued.** A second `claim` while the first is
   live returns `lease-held`.
3. **A budget is per run and starts fresh.** No pooled counter is inherited: the
   deadline and operation count come from the caller every time.
4. **`release` never throws** and is safe twice.
5. **The runtime never imports a capability.** It is a policy engine; the
   composition root registers what it runs.

- `packages/runtime/Test/**`

Nothing else.

2. **The stale fence is refused**: claim, expire, re-claim, then `withLease` with

3. **A second claim is refused** while the first is live.
4. **A budget is not inherited**: run A exhausts its operations, run B starts with a

5. **Admission refuses an unknown generation** - the generation the caller names must

export type Skill = { name: string; directory: string; description: string; references: string[] };
export type Finding = { skill: string; rule: string; detail: string };

export interface SkillContract {

TimeLine is to be left alone. The agentic database model - capabilities, generations,
leases with a fence, probes, beliefs, trace - is therefore built here, as rules that

# Why this shape

The consuming module is a SpacetimeDB module: tables and reducers compiled into the
published database. Nothing in Agentic can import `spacetimedb/server` - it is not a
dependency here, and adding one to test rules would be backwards.

So the rules live as pure functions over a *context interface* that the module will
satisfy, and the tables are described as data. The module keeps its own file; this
package holds what must be true.

| --- | --- |
| `docs/Design.md` | the layers and why a capability owns its port |
| `.hermes/research/d900b22a.md` | the SpacetimeDB model this implements: no reducer can execute DDL, so the catalog is data and the interpreter is fixed |
| `.hermes/research/432b4991.md` | the state chart: generation, lease and disclosure as concurrent coordinates |
| `TimeLine/Documentation/Reference/Spacetime-Model.md` | the position, already written |
| `TimeLine/Documentation/Reference/Spacetime-Time.md` | the four timestamps and three lags |
| `TimeLine/Documentation/Reference/Hidden-Properties.md` | private truth / probe / belief |

Read those five before writing anything. They are the requirement.

# Required behaviour

`packages/spacetime-catalog/src/` holds:

1. **`Tables.ts`** - the table descriptions as data: name, columns with type and key,
   and whether the table is append-only. `capability`, `generation`, `lease`,
   `probe`, `belief`, `trace`. This is what a module's declaration file would render
   from, and what a reader can diff.
2. **`Context.ts`** - the minimal context the reducers need, so they can be tested:

   ```ts
   export interface Context {
   	readonly sender: string;
   	readonly now: number;
   	find(table: string, id: string): Row | null;
   	insert(table: string, row: Row): void;
   	update(table: string, row: Row): void;
   	delete(table: string, id: string): void;
   }
   ```

3. **`Reducers.ts`** - `bind`, `claim`, `renew`, `probe`, `recordTrace` as pure
   functions over `Context`, each returning a result type rather than throwing:
   `{ ok: true } | { ok: false; reason: "admission-refused" | "lease-held" | "budget-exhausted" }`.
4. **`docs/Spacetime-Catalog.md`** in the workspace root - the adoption note: which
   declarations TimeLine copies, which reducers it wires to `ctx`, and the one thing
   that cannot be copied (the module's own `spacetimedb` import).

# The four invariants the reducers enforce

1. **Coherence** - `bind` appends a generation and refuses a manifest digest that
   names a capability not declared; no reducer writes under a generation that is not
   the latest bound one.
2. **Fence** - `claim` increments the fence; `renew` and any fenced write refuse a
   stale fence rather than applying late.
3. **Disclosure** - `probe` writes one audience-scoped row and returns only what it
   wrote; the private value is never a column a reader can select.
4. **Time** - every row takes `ctx.now`; no function reads a wall clock, and the
   lags are differences the caller computes.

# Contributing

Welcome. Before you start, read the [Code of Conduct](CODE_OF_CONDUCT.md) - the pledge, the
standards, the enforcement ladder and the address to report to all live there, and there is one copy
of them on purpose. By participating in this community you agree to abide by it. This file says the
rest: how work arrives, what a change has to pass, and how things are spelled.

---

## How work arrives

An issue first, then a card. An issue states the defect or the decision in the words of whoever
found it, with the command or the reading that shows it; a card is the unit of work - one owner, one
deliverable, and a body that says how the result will be checked. Work that starts without an issue
is fine. Work that ends without one leaves the next person nothing to read.

This repository has no RFC corpus. A decision that changes the design is a paragraph in
`Documentation/`, with the claim it rests on named as a source or marked as a decision. The existing
documents show the shape, and a document that changes its mind says so rather than rewriting the
earlier position: `Documentation/Observability.md` and `Documentation/Review.md` are both
corrections of an earlier pass, and both record the pass they correct.

---

## The gate

A change is ready when these pass, and none of them needs the network:

```
npm run check
npm run Test
npm run Format:Check
cd rust && cargo test --workspace
```

`npm run check` is the one that matters most. It refuses an import that reverses an arrow, and it
holds the feed bundler deterministic. A new package needs a `module.json` before it needs a test,
because the boundary check reads the manifest rather than the code.

The suites are fake-based by design: a page is a scripted responder, a browser is a scripted
launcher, and a deadline passes because the test advanced a clock it owns. A test that needs a real
browser belongs in an ad-hoc run under `.hermes/tools/`, not in the gate.

---

## Naming

One convention, everywhere in the tree: folders, files, identifiers and prose.

| Kind       | Rule                                                                   | Example                                                 |
| ---------- | ---------------------------------------------------------------------- | ------------------------------------------------------- |
| Folder     | PascalCase when it names a role; lowercase where an ecosystem fixes it | `Crate/BrowserCDP/Source`, `Package/browser-cdp/Source` |
| File       | PascalCase, one concept per file                                       | `Port.ts`, `Library.rs`, `Scope.md`                     |
| Acronym    | fully uppercase, in names and prose                                    | `CLI`, `URL`, `API`, `JSON`, `CDP`                      |
| Identifier | PascalCase for types and values; camelCase for locals                  | `CDPClient`, `cdpValue`                                 |

A compound takes the acronym whole: `CdpClient` is `CDPClient`, and a file or crate named after one
keeps it - `BrowserCDP`, `CDPSession`.

Two kinds of name sit outside the rule because something else already fixes their spelling: the
ecosystem's root files (`package.json`, `module.json`, `Cargo.toml`, `tsconfig.json`) and
wire-format field names such as `webSocketDebuggerUrl`. A third is narrower than it looks: a
TypeScript package's directory is the npm package's own name with its scope dropped, so it stays
lowercase - `Package/browser-cdp` - while everything above and below it follows the rule:
`Package/`, `Source/`, `Test/`.

The two trees have one shape: `Crate/<Name>/{Cargo.toml, module.json, Source/, Test/}` and
`Package/<Name>/{module.json, Source/, Test/}`. `Source/` holds the code and `Test/` the suites, in
both. The Rust half is the strict case because a module path is a file path:
`Crate/<Name>/Source/Library.rs` is the library root, `Fn/` holds operations, `Struct/` holds data
and contracts, and every module name matches its file.

A rename is mechanical: `git mv` the path, then follow every import, the `module.json` that names
the package, and the paths quoted in `Documentation/` and `README.md`. A half-renamed tree does not
pass the gate, which is the check.

//! The wiring: the only place that names a concrete adapter.
//!
//! Three builders, one per thing that needs a browser. Each returns a port,
//! never the adapter behind it, so a caller cannot reach past the composition
//! root into `chromiumoxide`.
//!
//! The pace is the tokio one because this binary is a tokio program. A
//! capability never sees it: it is handed a `Pace` through the driver and the
//! verifier, which is what keeps their dependency lists free of an executor.

use std::sync::Arc;

use AgenticBrowserCDP::{Browse, Chrome, ChromeOptions, Create as CreateSession, Options, Report, Tokio};
use AgenticChatDriver::{
	Create as CreateChat,
	Driver,
	Options as ChatOptions,
	Page as ChatPort,
	Selectors,
};

/// A browser session with the workspace's pace, reporting a failed release to
/// stderr.
///
/// The reporter writes to stderr rather than stdout because a caller that is
/// piping the tool's answer must not find a diagnostic in the middle of it.
pub fn Browser(Chrome:ChromeOptions) -> Arc<dyn Browse> {
	let Report:Report = Arc::new(|Target, Why| {
		eprintln!("browser-cdp: dispose of {} failed: {}", Target.Url, Why.Message());
	});
	Arc::new(CreateSession(
		Chrome::New(Chrome),
		Arc::new(Tokio),
		Options { Report, ..Options::default() },
	))
}

/// Where a chat driver's page comes from, and how it is read.
pub struct ChatSpec {
	/// The chat product's URL. With a bind it is only a fallback: the page
	/// keeps whatever URL it was already showing.
	pub Url:String,
	/// Attach to this endpoint instead of launching a browser.
	pub Attach:Option<String>,
	/// Bind this page on the attached browser instead of opening one.
	pub Bind:Option<String>,
	/// How the page is read.
	pub Selectors:Selectors,
}

/// A chat driver over a browser, with the workflow's page binding installed.
///
/// Three cases, stated rather than inferred: no endpoint launches a browser this
/// session owns; an endpoint with no bind opens a page in somebody else's
/// browser; an endpoint with a bind drives the page that is already there.
pub fn Chat(Browse:Arc<dyn Browse>, Spec:ChatSpec) -> Driver {
	let Page = match &Spec.Attach {
		Some(Endpoint) => Page::Attached(Browse, Endpoint.clone(), Spec.Bind.clone()),
		None => Page::Create(Browse),
	};
	let Options = ChatOptions { Selectors:Spec.Selectors, ..ChatOptions::New(Spec.Url) };
	CreateChat(Arc::new(Page) as Arc<dyn ChatPort>, Options, Arc::new(Tokio))
}

/// A design verifier over a browser, with the workflow's measurement binding
/// installed.
pub fn Design(Browse:Arc<dyn Browse>, Url:impl Into<String>) -> Verifier {
	CreateVerify(Arc::new(Measure::Create(Browse, Url)), Arc::new(Tokio))
}

/// What a caller passes to `Browser` when it wants a visible browser on the
/// machine's own display.
pub fn Visible() -> ChromeOptions { ChromeOptions { Executable:None, Headless:false, NoSandbox:false } }

/// What a caller passes to `Browser` when it wants a headless one.
pub fn Headless() -> ChromeOptions { ChromeOptions { Executable:None, Headless:true, NoSandbox:false } }

//! What each verb does.
//!
//! The two that need no browser are answered from the library alone, so a
//! machine with no Chromium can still check the corpus and every manifest. The
//! three that do need one build a session through [`crate::Fn::Composition`]
//! and hand it to a capability: nothing here calls an adapter directly.

use std::{sync::Arc, time::Duration};

use AgenticBrowserCDP::{OpenOptions, Ownership};
use AgenticChatDriver::{Chat, Mode, Question};
use AgenticDesignVerification::Verify;
use AgenticRuntime::{BlockOn, Call, Never};
use AgenticSkillContract::{Create as CreateContract, SkillContract};
use serde_json::json;

use crate::{
	Fn::{
		Composition::{Browser, Chat as ChatOver, ChatSpec, Design, Headless},
		VerifyModule::{ReadinessJSON, VerifyModule},
	},
	Struct::{Binary::Command::Verb, Manifest::All},
};

/// Run one verb, answering the text to print or the reason it could not be run.
pub async fn Run(Command:Verb) -> Result<String, String> {
	match Command {
		Verb::Manifests => {
			Ok(All
				.iter()
				.map(|Manifest| {
					format!(
						"{:<32} {:<12} {:<24} {}",
						Manifest.Name, Manifest.Kind, Manifest.Port, Manifest.State
					)
				})
				.collect::<Vec<String>>()
				.join("\n"))
		},
		Verb::Verify { Module } => {
			let Readiness = VerifyModule(&Module)?;
			let Text = serde_json::to_string_pretty(&ReadinessJSON(&Readiness)).unwrap_or_else(|_| "{}".to_string());
			if Readiness.Ready { Ok(Text) } else { Err(Text) }
		},
		Verb::Skills { Root, Json } => {
			let Contract = CreateContract();
			let Skills = Contract.Discover(&Root).await;
			let mut Findings = Vec::new();
			for Skill in &Skills {
				Findings.extend(Contract.Validate(Skill).await);
			}
			let Digest = Contract.Digest(&Skills);
			if Json {
				Ok(serde_json::to_string_pretty(&json!({
					"root": Root,
					"digest": Digest,
					"skills": Skills,
					"findings": Findings,
				}))
				.unwrap_or_else(|_| "{}".to_string()))
			} else {
				let mut Lines = vec![format!(
					"{} skill(s) under {Root}, {} finding(s), {Digest}",
					Skills.len(),
					Findings.len()
				)];
				for Finding in &Findings {
					Lines.push(format!("  {} {}: {}", Finding.Skill, Finding.Rule, Finding.Detail));
				}
				Ok(Lines.join("\n"))
			}
		},
		Verb::Browse { Url, Expression, Attach, Bind, Timeout } => {
			let Browse = Browser(Headless());
			let Call = Budget(Timeout);
			let Options = match (Attach, Bind) {
				(Some(Endpoint), Some(Key)) => OpenOptions::Existing(Endpoint, Key, Call.clone()),
				(Some(Endpoint), None) => OpenOptions::Attach(Endpoint, Call.clone()),
				(None, Some(_)) => {
					return Err(
						"binding an existing page needs --attach: a browser this tool launched has no page to bind"
							.to_string(),
					);
				},
				(None, None) => OpenOptions::Launch(Call.clone()),
			};
			let Ownership = Options.Ownership();
			let Target = Browse
				.Open(&Url, Options)
				.await
				.map_err(|Why| format!("{}: {}\n{}", Why.Code().Name(), Why.Message(), Why.Detail()))?;
			let Bound = Target.Url.clone();
			let Value = Browse
				.Evaluate(&Target, &Expression, Call)
				.await
				.map_err(|Why| format!("{}: {}\n{}", Why.Code().Name(), Why.Message(), Why.Detail()))?;
			Browse.Dispose(Target).await;
			Ok(serde_json::to_string_pretty(&json!({
				"url": Bound,
				"ownership": match Ownership {
					Ownership::Launched => "launched",
					Ownership::Attached => "attached",
				},
				"value": Value,
			}))
			.unwrap_or_else(|_| "{}".to_string()))
		},
		Verb::Chat { Url, Model, Question: Text, Attach, Bind, Selectors: Overrides, Observe, Timeout } => {
			let Selectors = match &Overrides {
				Some(Path) => {
					let Text = std::fs::read_to_string(Path).map_err(|Why| {
						format!("the selector file {Path} could not be read: {Why}")
					})?;
					let Parsed:serde_json::Value = serde_json::from_str(&Text).map_err(|Why| {
						format!("the selector file {Path} is not JSON: {Why}")
					})?;
					AgenticChatDriver::Struct::Selectors::Merged(&Parsed)
				},
				None => AgenticChatDriver::DefaultSelectors(),
			};
			let Driver = ChatOver(
				Browser(Headless()),
				ChatSpec { Url:Url.clone(), Attach, Bind, Selectors },
			);
			let Call = Budget(Timeout);
			// An observer is a sink and a stop, the way a mutation observer is a
			// callback and a disconnect: the driver pushes every read here and
			// this decides when it has seen enough. `--observe` writes each one
			// to stderr, so stdout stays the answer a caller is parsing.
			let mut Seen = |Observation:&AgenticChatDriver::Observation| {
				if Observe {
					eprintln!(
						"{}",
						serde_json::to_string(&json!({
							"count": Observation.Count,
							"chars": Observation.Text.chars().count(),
							"busy": Observation.Busy,
							"fresh": Observation.Fresh,
							"settled": Observation.Settled,
						}))
						.unwrap_or_else(|_| "{}".to_string())
					);
				}
				AgenticChatDriver::Control::Continue
			};
			let Answer = Driver
				.Observe(Question { Text, Mode:Mode::Search, Model }, Call, &mut Seen)
				.await
				.map_err(|Why| format!("{}: {}\n{}", Why.Code().Name(), Why.Message(), Why.Detail()))?;
			Ok(serde_json::to_string_pretty(&json!({
				"url": Url,
				"text": Answer.Text,
				"model": Answer.Model,
				"mode": Answer.Mode,
				"trace": Answer.Trace.iter().map(|Step| json!({
					"depth": Step.Depth,
					"label": Step.Label,
					"detail": Step.Detail,
				})).collect::<Vec<_>>(),
				"sources": Answer.Sources.iter().map(|Source| json!({
					"url": Source.Url,
					"label": Source.Label,
				})).collect::<Vec<_>>(),
			}))
			.unwrap_or_else(|_| "{}".to_string()))
		},
		Verb::Design { Url, Selectors, Timeout } => {
			let Verifier = Design(Browser(Headless()), Url.clone());
			let Measurements = Verifier
				.Measure(&Selectors, Budget(Timeout))
				.await
				.map_err(|Why| format!("{}: {}", Why.Code().Name(), Why.Message()))?;
			Ok(serde_json::to_string_pretty(&json!({
				"url": Url,
				"measurements": Measurements.iter().map(|Measurement| json!({
					"selector": Measurement.Selector,
					"present": Measurement.Present,
					"value": Measurement.Value,
				})).collect::<Vec<_>>(),
			}))
			.unwrap_or_else(|_| "{}".to_string()))
		},
	}
}

}

//! One module's readiness, from the manifest it ships.
//!
//! The check is the interesting part: a manifest that names four errors while
//! the crate's own type names three is a manifest that has drifted from its
//! code, and a harness reading it would prepare the wrong thing. Comparing the

//! Rust tree.

/// What one module reports about itself.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Readiness {
	/// The module's logical name.
	pub Module:String,
	/// What kind of thing it is.
	pub Kind:String,
	/// The port it provides.
	pub Port:String,
	/// The retention class it declares.
	pub State:String,
	/// The errors the manifest names.
	pub Manifest:Vec<String>,
	/// The codes the crate's own type declares.
	pub Code:Vec<String>,
	/// Whether the two agree, the state class is one of the four, and the
	/// manifest parses at all.
	pub Ready:bool,
	/// Why it is not ready, when it is not.
	pub Reason:Option<String>,
}

/// The codes each crate's type declares, by module name.
///
/// A crate with no error vocabulary of its own - the workflow and the
/// composition root - declares an empty list, and its manifest must too.
pub fn Declared(Name:&str) -> Option<Vec<&'static str>> {
	Some(match Name {
		"@agentic/runtime" => RuntimeCode::All().into_iter().map(RuntimeCode::Name).collect(),
		"@agentic/skill-contract" => SkillRule::All().into_iter().map(SkillRule::Name).collect(),
		"@agentic/chat-driver" => ChatCode::All().into_iter().map(ChatCode::Name).collect(),
		"@agentic/browser-cdp" => BrowserCode::All().into_iter().map(BrowserCode::Name).collect(),
		"@agentic/design-verification" => DesignCode::All().into_iter().map(DesignCode::Name).collect(),
		"@agentic/workflow" | "@agentic/composition" => Vec::new(),
		_ => return None,
	})
}

/// The states the manifest may name.
fn States() -> Vec<&'static str> {
	AgenticRuntime::States
		.into_iter()
		.map(AgenticRuntime::StateClass::Name)
		.collect()
}

/// Report one module.
pub fn VerifyModule(Name:&str) -> Result<Readiness, String> {
	let Some(Manifest) = Find(Name) else {
		return Err(format!(
			"{Name} is not a module this workspace ships; try one of: {}",
			crate::Struct::Manifest::All
				.iter()
				.map(|Manifest| Manifest.Name)
				.collect::<Vec<&str>>()
				.join(", ")
		));
	};
	let Some(Code) = Declared(Name) else {
		return Err(format!("{Name} has no code vocabulary in this binary"));
	};
	let Parsed:Value = serde_json::from_str(Manifest.JSON)
		.map_err(|Why| format!("{} ships a manifest that does not parse: {Why}", Manifest.Name))?;
	let ManifestErrors:Vec<String> = Parsed
		.get("provides")
		.and_then(|Provides| Provides.get("errors"))
		.and_then(Value::as_array)
		.map(|Errors| Errors.iter().filter_map(Value::as_str).map(str::to_string).collect())
		.unwrap_or_default();
	let Declared:Vec<String> = Code.iter().map(|Code| (*Code).to_string()).collect();
	let State = Parsed.get("state").and_then(Value::as_str).unwrap_or_default().to_string();
	let Reason = if ManifestErrors != Declared {
		Some(format!(
			"the manifest names [{}] and the crate names [{}]",
			ManifestErrors.join(", "),
			Declared.join(", ")
		))
	} else if !States().contains(&State.as_str()) {
		Some(format!("{State:?} is not one of the four state classes"))
	} else {
		None
	};
	Ok(Readiness {
		Module:Manifest.Name.to_string(),
		Kind:Manifest.Kind.to_string(),
		Port:Manifest.Port.to_string(),
		State,
		Manifest:ManifestErrors,
		Code:Declared,
		Ready:Reason.is_none(),
		Reason,
	})
}

/// A readiness report as the JSON a harness reads.

		"kind": Readiness.Kind,

--- FILE: Crate/BrowserCDP/Source/Fn/Classify.rs ---
//! The mapping from `chromiumoxide`'s errors onto the three codes.
//!
//! The rule is the port's, applied to a substrate that has more failure modes
//! than the port has codes:
//!
//! - **a dead socket is `browser-unavailable`.** A WebSocket error, an I/O
//!   error, no response at all, a channel that closed under a request, and a
//!   browser process that exited or never announced its endpoint all mean the
//!   same thing to a consumer: there is no browser to talk to. So do the
//!   failures that can only happen before a page exists - a URL that does not
//!   parse, a response that does not decode, a frame id that is not there.
//! - **a page that could not be used is `navigation-failed`.** A JavaScript
//!   exception, a protocol error naming the page, a scrolling failure: the
//!   transport is alive and the page is what went wrong.
//! - **a deadline is `timeout`.** `CdpError::Timeout` is the protocol's own
//!   timeout, which is the same event as the session's deadline from a
//!   consumer's side.
//!
//! `Fatal` is the second half of the mapping: it says which errors mean the
//! transport is gone, so the transport can report itself closed and the session
//! can classify the *next* failure as `browser-unavailable` rather than as a
//! page defect.

use chromiumoxide::error::CdpError;

use crate::Struct::Error::Error;

/// Map one substrate error onto the port's three codes, keeping the provider's
/// words in `detail`.
pub fn Classify(Cdp:&CdpError) -> Error {
	match Cdp {
		CdpError::Ws(Why) => {
			Error::Unavailable("the browser could not be reached", format!("the websocket failed: {Why}"))
		},
		CdpError::Io(Why) => {
			Error::Unavailable("the browser could not be reached", format!("the connection failed: {Why}"))
		},
		CdpError::NoResponse => Error::Unavailable("the browser did not answer", "the request produced no response"),
		CdpError::ChannelSendError(Why) => {
			Error::Unavailable(
				"the browser is no longer listening",
				format!("the request channel closed: {Why}"),
			)
		},
		CdpError::LaunchExit(Status, _) => {
			Error::Unavailable(
				"the browser exited before it was ready",
				format!("the process exited with {Status:?}"),
			)
		},
		CdpError::LaunchTimeout(_) => {
			Error::Unavailable("the browser never announced its endpoint", "the launch timed out")
		},
		CdpError::LaunchIo(Why, _) => {
			Error::Unavailable(
				"the browser could not be started",
				format!("the process could not be spawned: {Why}"),
			)
		},
		CdpError::NotFound => Error::Unavailable("the browser did not answer", "the requested value was not found"),
		CdpError::Url(Why) => {
			Error::Unavailable("the browser could not be reached", format!("the endpoint is not a URL: {Why}"))
		},
		CdpError::Serde(Why) => {
			Error::Unavailable(
				"the browser answered something this client cannot read",
				format!("the response did not decode: {Why}"),
			)
		},
		CdpError::DecodeError(Why) => {
			Error::Unavailable(
				"the browser answered something this client cannot read",
				format!("the payload did not decode: {Why}"),
			)
		},
		CdpError::FrameNotFound(Frame) => {
			Error::Unavailable("the page is no longer there", format!("frame {Frame:?} was not found"))
		},
		CdpError::Timeout => Error::Timeout("the page did not answer in time", "the protocol reported a timeout"),
		CdpError::JavascriptException(Details) => {
			Error::Navigation("the page threw while it was being asked", format!("{Details:?}"))
		},
		CdpError::ChromeMessage(Message) => Error::Navigation("the page could not answer", Message.clone()),
		CdpError::Chrome(Why) => Error::Navigation("the page could not answer", format!("the protocol reported {Why}")),
		CdpError::ScrollingFailed(Why) => Error::Navigation("the page could not be scrolled", Why.clone()),
		CdpError::UnexpectedWsMessage(Message) => {
			Error::Navigation("the browser sent a message this client does not handle", format!("{Message:?}"))
		},
		CdpError::InvalidMessage(Message, Why) => {
			Error::Unavailable(
				"the browser sent a message this client cannot read",
				format!("{Message}: {Why}"),
			)
		},
	}
}

/// Whether the transport is gone after this error.
pub fn Fatal(Cdp:&CdpError) -> bool { matches!(Classify(Cdp).Code(), crate::Struct::Error::Code::Unavailable) }

/// The page-error rule: a closed transport wins over a page defect, because the
/// socket is gone rather than the page being wrong. A deadline is left alone -
/// it is the caller's own bound, not a fact about the socket.
pub fn ClassifyPage(Why:Error, Closed:bool) -> Error {
	match Why.Code() {
		crate::Struct::Error::Code::Timeout => Why,
		_ if Closed => {
			Error::Unavailable("the transport closed while the page was being asked", Why.Detail().to_string())
		},
		_ => Why,
	}
}

--- FILE: Crate/BrowserCDP/Source/Library.rs ---
//! `agentic.browse`: the concrete browser substrate.
//!
//! Attach and launch are separate operations, not a boolean hidden in a
//! constructor, because they differ in who owns the process: a session that
//! launched a browser may close it, and a session that attached to one may not.
//! [`Struct::Port::Ownership`] records which happened, and disposal reads it.
//!
//! Every classification rule lives in [`Fn::Classify`], in one place:
//!
//! - silence is a timeout. Nothing but the deadline can end a page that never
//!   answers, so a hang is reported as `timeout` and never as a dead transport;
//! - a closed transport is `browser-unavailable`, whatever error arrived with
//!   it, because the socket is gone rather than the page being slow;
//! - a live transport that could not be used is `navigation-failed`.
//!
//! Cancellation belongs to the caller: every operation races the caller's
//! signal and its own deadline through [`AgenticRuntime::Bound`], and both lose
//! to `timeout` rather than to a bare error, so a consumer can distinguish "I
//! gave up" from "the browser broke".
//!
//! `chromiumoxide` is behind [`Struct::Chrome`] and nowhere else. Nothing in
//! the session, the port or the transports mentions it: a different substrate
//! would replace one file.

#![allow(non_snake_case)]
#![allow(non_upper_case_globals)]
#![allow(clippy::upper_case_acronyms)]

pub mod Fn;

//! A cancellation source a tokio caller can fire from anywhere.
//!
//! The runtime's `Signal` is executor-neutral and works here, but a tokio
//! program usually already has a token it shares with other tasks, and
//! converting one into the port's shape is cheaper than a second source of
//! truth. This is that conversion and nothing else.

use std::sync::Arc;

use AgenticRuntime::{Cancellation, FutureBox};
use tokio_util::sync::CancellationToken;

/// A token, seen as a cancellation.
#[derive(Debug, Clone, Default)]
pub struct Stop(CancellationToken);

impl Stop {
	/// A token nobody has cancelled.
	pub fn New() -> Arc<Self> { Arc::new(Self(CancellationToken::new())) }

	/// Cancel it, waking every waiter.
	pub fn Cancel(&self) { self.0.cancel(); }

	/// The token itself, for a caller that wants to share it.
	pub fn Token(&self) -> CancellationToken { self.0.clone() }
}

impl Cancellation for Stop {
	fn IsCancelled(&self) -> bool { self.0.is_cancelled() }

	fn Cancelled(&self) -> FutureBox<'_, ()> {
		let Token = self.0.clone();
		Box::pin(async move { Token.cancelled().await })
	}
}

//! The concrete substrate: `chromiumoxide`, and the only file that names it.
//!
//! Two entry points, because attach and launch are different operations:
//! `Launch` starts a browser process this session owns, and `Attach` connects
//! to one that is already listening. The session decides which to call from
//! [`crate::Struct::Port::OpenOptions::AttachTo`], and records the ownership it
//! implies, so disposal closes only what was launched.
//!
//! The handler task is not optional. `chromiumoxide`'s usage model is a
//! `Browser` plus a `Handler` that must be polled: a client that keeps the
//! browser and drops the handler gets a connection that accepts commands and
//! never answers them. The task is owned here and aborted on release.
//!
//! A caller must already be inside a tokio runtime: `Launch` and `Attach` spawn
//! the handler, and a spawn outside a runtime panics. That is the composition
//! root's contract, and the only place in the workspace where it applies.

use std::{
	path::PathBuf,
	sync::{
		Arc,
		Mutex,
		MutexGuard,
		atomic::{AtomicBool, Ordering},
	},
};

use AgenticRuntime::{Call, FutureBox};
use chromiumoxide::{Browser, BrowserConfig, Handler, Page};
use futures_util::StreamExt;
use serde_json::Value;
use tokio::task::JoinHandle;

use crate::{
	Fn::Classify::{Classify, Fatal},
	Struct::{
		Error::Error,
		Transport::{Launcher, PageWant, Transport},
	},
};

/// How to start or reach a browser.
#[derive(Clone, Debug, Default)]
pub struct ChromeOptions {
	/// The browser binary, when it is not the one `chromiumoxide` finds.
	pub Executable:Option<PathBuf>,
	/// Whether to run without a window. Off means a visible browser, which is
	/// what an attached session usually wants to share with a person.
	pub Headless:bool,
	/// Whether to pass `--no-sandbox`. Needed in containers, never on a
	/// desktop.
	pub NoSandbox:bool,
}

/// The `chromiumoxide` launcher.
pub struct Chrome {
	Options:ChromeOptions,
}

impl Chrome {
	/// A launcher with the caller's configuration.
	pub fn New(Options:ChromeOptions) -> Arc<Self> { Arc::new(Self { Options }) }

	/// How long an attach waits for the browser to hand over the sessions of
	/// pages that were already open.
	///
	/// Attaching to a target is a round trip, so a page is not in the handler's
	/// map the instant it is requested. This is that moment, not a timeout on
	/// the browser: it is bounded so a browser that really does not hold the
	/// page is reported rather than waited on.
	pub const PageGrace:std::time::Duration = std::time::Duration::from_secs(2);

	/// The page an attach binds to, chosen by target id first and by URL
	/// prefix second.
	///
	/// Target id is exact and URL is not, so the order matters: two tabs of one
	/// product are told apart by id, and a caller that only knows the URL gets
	/// the first page that starts with it. A key that matches nothing is
	/// `navigation-failed` - the browser answered, and the page the caller
	/// named is not in it.
	async fn Bound(Key:&str, Pages:Vec<Page>) -> Result<Page, Error> {
		let mut Fallback = None;
		let mut Seen = Vec::new();
		for Page in Pages {
			let Id = Page.target_id().as_ref().to_string();
			let Url = Page.url().await.ok().flatten().unwrap_or_default();
			Seen.push(format!("{Id} {Url}"));
			if Id == Key {
				return Ok(Page);
			}
			if Fallback.is_none() && !Url.is_empty() && Url.starts_with(Key) {
				Fallback = Some(Page);
			}
		}
		match Fallback {
			Some(Page) => Ok(Page),
			None => Err(Error::Navigation(
				"the browser holds no page matching the one asked for",
				format!("no target id or URL starts with {Key}; it holds [{}]", Seen.join(" | ")),
			)),
		}
	}

	/// A browser whose handler is already being polled, bound to `Want`.
	async fn Bind(mut Browser:Browser, Handler:Handler, Want:PageWant<'_>) -> Result<Arc<dyn Transport>, Error> {
		let Endpoint = Browser.websocket_address().clone();
		let Task = tokio::spawn(async move {
			let mut Handler = Handler;
			while Handler.next().await.is_some() {}
		});
		let Page = match Want {
			PageWant::Fresh(Url) => Browser.new_page(Url).await.map_err(|Why| Classify(&Why))?,
			PageWant::Existing(Key) => {
				// A browser announces no `targetCreated` for the tabs that were
				// already open when this client connected, so the handler's own
				// map is empty until it asks. Without this fetch every bind
				// reports that the page is not there.
				if let Err(Why) = Browser.fetch_targets().await {
					return Err(Error::Unavailable(
						"the browser would not list its pages",
						format!("target enumeration failed: {Why}"),
					));
				}
				// The attach that `fetch_targets` starts is a round trip, and a
				// page cannot be handed out until its session arrives. So the
				// match is retried until the grace runs out, and a browser that
				// holds other pages but not this one is still reported as not
				// holding it - which is the difference between a race and a
				// wrong target id.
				let Start = std::time::Instant::now();
				loop {
					let Pages = Browser.pages().await.map_err(|Why| Classify(&Why))?;
					match Self::Bound(Key, Pages).await {
						Ok(Page) => break Page,
						Err(_) if Start.elapsed() < Self::PageGrace => {
							tokio::time::sleep(std::time::Duration::from_millis(25)).await;
						},
						Err(Why) => return Err(Why),
					}
				}
			},
		};
		let Url = Page.url().await.ok().flatten().unwrap_or_default();
		Ok(Arc::new(ChromeTransport {
			Page,
			Url,
			Browser:Mutex::new(Some(Browser)),
			Handler:Mutex::new(Some(Task)),
			Endpoint,
			Closed:AtomicBool::new(false),
		}))
	}
}

impl Launcher for Chrome {
	fn Launch<'a>(&'a self, Url:&'a str, _Call:Call) -> FutureBox<'a, Result<Arc<dyn Transport>, Error>> {
		Box::pin(async move {
			let mut Builder = BrowserConfig::builder();
			if let Some(Path) = &self.Options.Executable {
				Builder = Builder.chrome_executable(Path);
			}
			if self.Options.Headless {
				Builder = Builder.new_headless_mode();
			} else {
				Builder = Builder.with_head();
			}
			if self.Options.NoSandbox {
				Builder = Builder.no_sandbox();
			}
			let Config = Builder
				.build()
				.map_err(|Why| Error::Unavailable("the browser configuration is not usable", Why.to_string()))?;
			let (Browser, Handler) = Browser::launch(Config).await.map_err(|Why| Classify(&Why))?;
			Self::Bind(Browser, Handler, PageWant::Fresh(Url)).await
		})
	}

	fn Attach<'a>(
		&'a self,
		Endpoint:&'a str,
		Want:PageWant<'a>,
		_Call:Call,
	) -> FutureBox<'a, Result<Arc<dyn Transport>, Error>> {
		Box::pin(async move {
			let (Browser, Handler) = Browser::connect(Endpoint).await.map_err(|Why| Classify(&Why))?;
			Self::Bind(Browser, Handler, Want).await
		})
	}
}

/// One page on one browser, and the handler that keeps it answering.
struct ChromeTransport {
	Page:Page,
	/// Where the page was when this transport was bound.
	Url:String,
	Browser:Mutex<Option<Browser>>,
	Handler:Mutex<Option<JoinHandle<()>>>,
	Endpoint:String,
	Closed:AtomicBool,
}

impl ChromeTransport {
	fn Lock<T>(Guard:&Mutex<T>) -> MutexGuard<'_, T> { Guard.lock().unwrap_or_else(|Poison| Poison.into_inner()) }

	/// Stop polling the handler, which is what ends this session's side of the
	/// connection whatever happens to the browser.
	fn Stop(&self) {
		if let Some(Handler) = Self::Lock(&self.Handler).take() {
			Handler.abort();
		}
		self.Closed.store(true, Ordering::SeqCst);
	}
}

impl Transport for ChromeTransport {
	fn Endpoint(&self) -> &str { &self.Endpoint }

	fn Url(&self) -> &str { &self.Url }

	fn Closed(&self) -> bool { self.Closed.load(Ordering::SeqCst) }

	fn Evaluate<'a>(&'a self, Expression:&'a str, _Call:Call) -> FutureBox<'a, Result<Value, Error>> {
		Box::pin(async move {
			match self.Page.evaluate(Expression).await {
				Ok(Result) => Ok(Result.value().cloned().unwrap_or(Value::Null)),
				Err(Why) => {
					if Fatal(&Why) {
						self.Closed.store(true, Ordering::SeqCst);
					}
					Err(Classify(&Why))
				},
			}
		})
	}

	fn Close(&self) -> FutureBox<'_, ()> {
		Box::pin(async move {
			// Closing the page first runs its unload hooks; then the browser
			// this session launched, which nobody else may close.
			let _ = self.Page.clone().close().await;
			// Taken out of the lock before the await: a guard held across one
			// is not `Send`, and a browser handle is the only thing
			// that needs to survive.
			let Browser = Self::Lock(&self.Browser).take();
			if let Some(mut Browser) = Browser {
				let _ = Browser.close().await;
			}
			self.Stop();
		})
	}

	fn Detach(&self) -> FutureBox<'_, ()> {
		Box::pin(async move {
			// Somebody else owns this browser: stop listening and leave it
			// running.
			self.Stop();
		})
	}
}

//! The three failure modes `module.json` declares, and no others.
//!
//! One enum, one variant per code, `detail` kept apart from the message in
//! every one of them: what was observed is the only thing that says which part
//! of the transport broke, and a sentence written for a human loses it.

use std::fmt;

/// The codes, in the order the manifest names them.
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub enum Code {
	/// The transport is gone: a dead socket, not a slow page.
	Unavailable,
	/// The page exists but could not be used: it failed to load, or it threw.
	Navigation,
	/// The signal fired or the deadline passed before an answer arrived.
	Timeout,
}

impl Code {
	/// The string the manifest uses.
	pub const fn Name(self) -> &'static str {
		match self {
			Code::Unavailable => "browser-unavailable",
			Code::Navigation => "navigation-failed",
			Code::Timeout => "timeout",
		}
	}

	/// Every code, so a harness can compare the manifest against the type.
	pub const fn All() -> [Code; 3] { [Code::Unavailable, Code::Navigation, Code::Timeout] }

	/// The code a manifest string names, if it names one of the three.
	pub fn Parse(Value:&str) -> Option<Code> { Code::All().into_iter().find(|Code| Code.Name() == Value) }
}

/// The one error type a `Browse` call fails with.
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Error {
	/// The transport is gone.
	Unavailable {
		/// The sentence a human reads.
		Message:String,
		/// What was observed, kept apart from the sentence.
		Detail:String,
	},
	/// The page exists but could not be used.
	Navigation {
		/// The sentence a human reads.
		Message:String,
		/// What was observed.
		Detail:String,
	},
	/// The signal fired or the deadline passed.
	Timeout {
		/// The sentence a human reads.
		Message:String,
		/// What was observed.
		Detail:String,
	},
}

impl Error {
	/// A dead transport.
	pub fn Unavailable(Message:impl Into<String>, Detail:impl Into<String>) -> Self {
		Error::Unavailable { Message:Message.into(), Detail:Detail.into() }
	}

	/// A page that could not be used.
	pub fn Navigation(Message:impl Into<String>, Detail:impl Into<String>) -> Self {
		Error::Navigation { Message:Message.into(), Detail:Detail.into() }
	}

	/// A deadline that passed or a caller that gave up.
	pub fn Timeout(Message:impl Into<String>, Detail:impl Into<String>) -> Self {
		Error::Timeout { Message:Message.into(), Detail:Detail.into() }
	}

	/// The code this failure carries.
	pub const fn Code(&self) -> Code {
		match self {
			Error::Unavailable { .. } => Code::Unavailable,
			Error::Navigation { .. } => Code::Navigation,
			Error::Timeout { .. } => Code::Timeout,
		}
	}

	/// The sentence a human reads.
	pub fn Message(&self) -> &str {
		match self {
			Error::Unavailable { Message, .. } | Error::Navigation { Message, .. } | Error::Timeout { Message, .. } => {
				Message
			},
		}
	}

	/// What was observed, which may be empty.
	pub fn Detail(&self) -> &str {
		match self {
			Error::Unavailable { Detail, .. } | Error::Navigation { Detail, .. } | Error::Timeout { Detail, .. } => {
				Detail
			},
		}
	}
}

impl fmt::Display for Error {
	fn fmt(&self, Formatter:&mut fmt::Formatter<'_>) -> fmt::Result {
		write!(Formatter, "{}: {}", self.Code().Name(), self.Message())
	}
}

impl std::error::Error for Error {}
