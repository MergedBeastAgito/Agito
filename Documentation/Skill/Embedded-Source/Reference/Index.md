# Reference

Files in this directory, and what each one carries.

- `Index.md` - this list.
- `Format-To-File.md` - the worked instance: `Expression/ReadMode` as a `.ts` file, its call site,
  the two artefacts the build writes, and the `diff` that proves the artefact is the source minus
  its declarations.

A reference file is added when a worked instance outgrows a rule in `SKILL.md`, not before: the rule
stays in the skill and the instance moves here.
