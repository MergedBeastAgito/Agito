# Reference

The files this skill's `SKILL.md` defers to.

- `Decision-Model-Loop.md` - wiring a decision model into a driving loop: the request shape a
  decision endpoint takes, the probability to gate on and how to choose it, the state that carries a
  verdict and a sentence, the dimension blocks a tick sends, and the lane that makes the round trip
  auditable.
- `Loop-Traps.md` - four failures in how a run is read rather than how it is driven: a correlation
  on a monotone series, a verdict tally written from remembered words, a cloned deadline that
  expires mid-run, and a tree a background worker is editing.
- `Overlay-Injection.md` - installing the HUD into a canvas page: the two grammars a template
  literal imposes, `cssText` against a stylesheet a CSP blocks, the one paint timer, the four DOM
  assertions that prove a panel is updating, and the layout and grouping rules that keep it
  readable.
- `Worked-Instance.md` - one WebGPU racing port read end to end: its page surface, the memory map
  its own source states, the tap semantics of its input API, the cue thresholds, the motion signal
  calibrated at both ends, and the loop parameters that behaved.
