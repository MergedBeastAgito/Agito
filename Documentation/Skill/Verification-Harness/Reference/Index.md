# Reference

Files in this directory, and what each one carries.

- `Index.md` - this list.
- `Recorder.md` - the command recorder: replacing a tool's runner with a function that appends `argv`
  and answers with a fixture, and the four rules that keep the recording honest.
- `False-Green.md` - the catalogue of checks that passed while the change was broken: quoting,
  paths and collation, shell status, log verdicts, state that was not forced, and assertions shaped
  around the code instead of the requirement.
